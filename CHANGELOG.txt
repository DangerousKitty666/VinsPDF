VinsPDF 0.29.1 — 22 November 2026

Fixes the "Cannot access a disposed object. Object name: EditorPalette" crash
when closing an edited document tab or window.

- Closed documents stop panel visibility callbacks before disposing their tools.
- Each document has one panel visibility handler, with safe disposal and recovery.
- Moving tabs transfers panel ownership; closing the old window cannot destroy
  another document's editing panel.
- Delayed layer updates ignore closed/replaced panels. Save, discard and cancel
  continue to work, including pending text edits.
- About / update status displays the complete patch version.

Reproduced the error on 0.29. All seven new close/save/cancel/detach/recovery tests
pass after the fix, including verification that saved test text remains in the PDF.
The release workflow now runs these tests before publishing installers.

Install VinsPDF-Setup-0.29.1.exe, or use About > Check for updates.
