VinsPDF 0.29 — 22 November 2026

Download VinsPDF-Setup-0.29.exe or use About > Check for updates.

- Centred clickable original Home logo; three-column page overview beside PAGES.
- Compact centred page input and tab captions, filename tooltips, larger + and
  quick-close x buttons. PDF page labels, fitted-page wheel turns and F11.
- Search with highlighted results, navigation and case matching. Separate viewer
  Highlight tool saves native yellow PDF annotations.
- About matches StruKit's text, arrangement and animated GIF.
- Editor defaults to 90% opacity with Select and Pan. Removed Move selected,
  marker and list controls; redesigned text colour button.
- Thinner resizable inline border. Nearby body paragraphs form one box and reflow
  together with paragraph breaks. Wrapping survives font changes and saving.
- Recent undo/redo views repaint immediately without moving the camera.
- Reduced editable/flattened PDF and PNG/JPEG/TIFF/BMP exports, standard DPI
  dropdown and fast/thorough lossless compression for editable PDFs.
- Redesigned Extract dialog. Organise has Save as and Save later; deferred changes
  stay unsaved until the original document is explicitly saved.

Tested on current A012 (15 pages) and A014 (24 pages), plus synthetic fixtures.
Original drawings remain unchanged and private. See Performance.txt for timings
and checks, and README.txt for controls and limits. Page labels need PDF metadata;
OCR and mixed formatting within one item are not included.
