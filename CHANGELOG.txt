VinsPDF 0.30 (the 0.3 update) — 22 November 2026

- Select and edit text inside ordinary nested PDF groups, including independently
  editing repeated groups. Preparation happens on entering editing, not opening.
- Edit directly in the on-page border with mixed font weights, sizes and colours.
  Font controls apply to selected text; single-line text no longer wraps on entry.
- Select and copy PDF text without entering the editor.
- Page overview fits three columns and three rows at its default size.
- Smaller colour control without the red underline; Layout moved after Width.
- Restore standard Windows snap/resize styles while retaining the dark title bar.
- Strong editable compression downsamples eligible images with adjustable DPI and
  JPEG quality. Lossless Fast and Thorough options remain available.
- Preserve the editing-panel close/crash fixes from 0.29.1.
- Prevent missing letters when saving documents with multiple embedded subsets
  of the same font; preserve displayed text/path colours on regenerated pages.
- Keep separate bullet items out of paragraph groups and infer normal line gaps.
- F11 restores the snapped window position and size.

Ordinary groups are supported. Transparency/reference groups and inline-image
streams remain untouched. Unavailable PDF fonts use an installed substitute.
Regenerating an edited page can slightly change glyph spacing. The HTM document
was checked for text/colour preservation, save/reopen and unchanged other pages;
exact font metrics and kerning are not guaranteed.
Strong compression changes image quality, while keeping text and vectors editable.

Numbered 0.30 so existing installations recognise it as newer than 0.29.1.
Install VinsPDF-Setup-0.30.exe, or use About > Check for updates.
