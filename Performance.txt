VinsPDF 0.28 validation — 21 November 2026

Test documents: current user-approved A012 (15 pages, 54.6 MB) and A014
(24 pages, 62.1 MB). Originals were not modified or uploaded.

All 39 pages rendered successfully. At 1400-pixel preview size, median first
page-render time across each document was 1316 ms (A012) and 1181 ms (A014).
The slowest pages took 6202 ms and 4930 ms. Cached repeat renders were under
1 ms; the first A014 revisit after cache eviction took 1636 ms. Zoom viewport
renders took 498 ms and 920 ms. These are local observations, not controlled
cold-start benchmarks or guarantees; caches were not cleared and brief UI tests
ran during part of the rendering run. No speedup claim is based on this run.
First-page preview pixels match 0.27 on both drawings.

Both drawings passed grouped line editing, fonts/spacing/header-footer changes,
save/reopen and preservation of page counts, media/crop boxes, rotations and
original layer names. The 0.25, 0.26 and 0.27 engine regressions pass.

New engine checks cover linked underline/strike/highlight shapes, text style
persistence, movement/rotation/delete/undo, lists, wrapping, justification,
PNG/JPEG/TIFF/BMP dimensions and greyscale, reduced PDF export, page ranges,
reordering/rotation and rejection of rasters above the 24-megapixel limit.

WinForms event tests exercise the compact floating panel, inline frame resizing,
Select-mode centre movement/resize/rotation, body marquee, unchanged camera on
undo, Save/Don't save/Cancel, save failure/recovery, thumbnail drag order and
asynchronous organiser previews. Captured dialogs, palette, scrollbar and PDF
renders were visually reviewed. These are internal event tests/captures, not
exhaustive physical-input, high-DPI, multi-monitor or printer tests.

Local installer checks use an isolated folder without changing the user's
registration. GitHub's clean Windows runner checks full per-user installation,
PDF association/icon registration, replacement in place and uninstall before
publishing. See the release Actions run for the final result.

Limits: mixed formatting within an item is not supported; applied text is stored
as separate lines. Layer groups are not full PDF optional-content authoring.
Page-copy tools may omit document-level features; reduced PDF/image exports
flatten pages. See README.txt for controls and the complete scope.
